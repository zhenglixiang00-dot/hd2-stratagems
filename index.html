SUPER EARTH // STRATAGEM DATABASE

绝地潜兵2 · 自定义战备数据库

这是「Call For Stratagems On Phone」客户端使用的自定义战备数据源。
在 App 的 设置 → 信息 → 数据库版本 → 自定义 中，把本页地址（/index.json）填入即可使用。

index.json（清单） stratagem_db.json（战备数据）

使用方法

  1. 打开手机 App，进入 设置 → 信息 → 数据库版本。
  2. 选择「自定义」，粘贴本页对应的 index.json 地址。
  3. 点「更新数据库」，等待「数据库更新完成」提示即可。
